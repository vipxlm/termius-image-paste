# 配置、目录和本地数据

本文对应 `v2.1.0` 起的简化服务器表单。旧版 `v2.0.0` 操作不同，请先查看 [首页的版本说明](../README.md#下载与版本)。

## 连接服务器

1. 填写主机地址、SSH 端口和用户名。服务器名称可以留空，也不需要与 Termius 标签对应。
2. 选择密码或密钥登录。
3. 点击“登录并保存”，首次连接核对主机指纹。
4. 登录成功后检查图片保存目录，再回到 Termius 使用贴图快捷键。

密码登录自动生成或复用专用 ED25519 密钥，将公钥追加到服务器授权，后续贴图使用该密钥。已有授权保留，不覆盖已有私钥、公钥或不匹配的密钥对。密码只用于本次操作，不写入配置、日志、命令行或环境变量；密码辅助进程通过短时一次性本机通道获取密码。

密钥登录使用已获服务器授权的本地私钥。当前首次授权支持普通 SSH 密码，不自动处理 MFA、OTP 或私钥口令；遇到这些要求时，应先完成必要的服务器授权，再选用助手可使用的密钥。

每台服务器独立保存主机公钥。读取指纹的步骤不登录服务器、不保存信任或修改授权；确认后正式 SSH 连接严格校验已保存的主机身份。修改地址或端口后需要重新核对，身份变化时不会自动替换信任记录。

## 图片保存目录

默认目录是远端实际用户主目录下的 `.cache/termius-images`，首次登录时自动创建。

自定义目录使用 Linux 绝对路径。登录后可以“选择远端目录”浏览文件夹，选好后再次登录并保存，以验证目录可写。浏览只读取目录列表；密码首次配置时可以创建填写的目录，自选目录应确认当前用户有写入权限。

Windows 与 Linux 都需要支持 SFTP 的系统 OpenSSH 客户端，推荐 9.0 或更新版本。上传显式使用 SFTP，客户端不支持时会报错。

## 窗口、快捷键与结果

Windows 和 Linux X11 仅在 Termius 前台时占用已配置的贴图快捷键。Windows 自动目标识别另有版本和调试接口要求，参见 [连接识别说明](termius-real-connection.md)。Linux X11 手动选择目标；路径必须能由当前键盘布局完整表示，否则只提供路径供手动使用，不部分输入，也不更改键盘映射。

Wayland 使用助手窗口内上传和手动取路径，不启用跨应用快捷键或自动输入。

窗口内粘贴、拖图或选择文件不会向其他窗口输入。完整结果始终显示在概览页，系统通知取决于桌面和通知权限。自动输入不按回车；离开目标窗口、取消操作或修改设置会阻止后续自动输入。已经上传的图片仍保留。

Windows 关闭窗口可驻留托盘。Linux 托盘依赖 StatusNotifier 宿主；无法确认托盘可见时，保留后台会最小化到任务栏，避免无法找回窗口。

## 本地配置与清理

实际配置位置可在“快捷键与偏好”中查看。通常为：

| 系统 | 配置目录 |
| --- | --- |
| Windows | `%APPDATA%\com.sean.termius-image-paste` |
| Linux | `$XDG_CONFIG_HOME/com.sean.termius-image-paste`；未设置时为 `~/.config/com.sean.termius-image-paste` |

首次启动可读取旧 Windows 版 `%LOCALAPPDATA%\TermiusImagePaste\settings.json`，复用服务器、主机指纹、密钥路径及快捷键。旧配置和密钥保留，新版保存到独立目录；原配置损坏时停止保存，不用默认配置覆盖。

助手只保存本机设置，不同步私钥。本地临时 PNG 在操作完成后清理；最近一次结果只保存在本次运行内存中。远端图片长期保留，删除本机服务器配置不会删除远端文件、SSH 密钥或已有授权。
